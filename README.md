# VibeCode Labs — policies

Privacy policies and support pages for the extensions VibeCode Labs publishes on
the Chrome Web Store.

Published at **https://valen-leyes.github.io/vibecode-labs/**

| Extension | Privacy policy | Support | Fix guides |
|---|---|---|---|
| Micro-Formatter | [`micro-formatter/`](micro-formatter/) | [`micro-formatter/support.html`](micro-formatter/support.html) | [`docs/`](docs/) |

## What this repository is

Static HTML and one stylesheet, served by GitHub Pages. Nothing else: no
extension code, no build step, no scripts.

The `docs/` folder holds the fix guides. Each guide is its own page under a
symptom-named directory, because other places link to them directly:
`docs/` is the base URL and the page name is appended to it. The pages load no external fonts,
stylesheets or analytics, so reading a policy makes no third-party requests.

The extension source is not public. These pages exist so the policies are
readable without a session or a JavaScript-capable client, which is what a store
review requires.

## Reporting a problem

Open an issue here. For anything you would rather not post publicly, use the
contact address on the extension's store listing.
