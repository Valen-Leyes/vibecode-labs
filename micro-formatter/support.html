Micro-Formatter — Support

Applies to Micro-Formatter 1.0.1 and later · Last updated 8 November 2026

Report a problem

Open an issue at github.com/Valen-Leyes/vibecode-labs/issues. The store listing also shows a contact address if you would rather write privately.

What to include

  • your Chrome version (chrome://version);
  • the page or editor you copied from, if the text arrived in a shape the extension did not fix;
  • what you expected and what you got — a couple of representative lines is enough.

The extension collects no diagnostics, so there is no log to attach: a short description of the input is the most useful thing you can send.

Fix guides

Each kind of copy-paste damage has a short page: the symptom, why it happens, the manual fix, and what the extension does about it. Start at the fix guides index if you are not sure which one applies.

Common questions

Nothing happens when I right-click selected text. The menu item only appears while text is selected. If it is missing, reload the page after installing the extension.

The result did not replace my text. In a rich editor (Google Docs, some webmail) the extension cannot always write back, so it says so and leaves the cleaned text on the clipboard — paste it over your selection yourself.

Does it send my text anywhere? No. See the privacy policy.
