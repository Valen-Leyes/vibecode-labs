Hidden Character Remover — Support

Applies to Hidden Character Remover 0.1.0 and later · Last updated 10 November 2026

Report a problem

Open an issue at github.com/Valen-Leyes/vibecode-labs/issues. The store listing also shows a contact address if you would rather write privately.

What to include

  • your Chrome version (chrome://version);
  • how you ran the extension — context menu, Alt+Shift+H, or the paste box;
  • the text you expected to be cleaned, or the characters you expected it to find, and what happened instead. If you can, say which character misbehaved: a zero-width space pasted out of a browser console looks like \u200B.

The extension collects no diagnostics, so there is no log to attach: a short description of the input is the most useful thing you can send.

Common questions

Nothing happens when I right-click selected text. The menu item only appears while text is selected. If it is missing, reload the page after installing the extension.

It says a page cannot be read. Chrome does not allow any extension to script its own pages (chrome://…), the Chrome Web Store, or the built-in PDF viewer. Copy the text, open the popup and paste it there — the paste box does the same cleaning.

The shortcut does nothing. Alt+Shift+H is a suggestion, and another extension may already own it. Reassign it at chrome://extensions/shortcuts.

It found characters but the text looks the same. Invisible characters are invisible. The receipt counts them per kind, which is the only visible evidence they were there; the copy button gives you the cleaned text.

It says "no hidden characters found" but the text is still wrong. The extension only removes the character classes listed on the store page: zero-width characters, soft hyphens, byte-order marks, non-breaking and narrow spaces, bidirectional controls, and — when you ask — smart quotes, dashes and HTML tags. It does not reflow paragraphs, fix spelling, or reword anything.

My smart quotes were not removed. Check that "Keep smart quotes and dashes" is off in Options; the receipt marks those counts as kept when it is on.

Why did my non-breaking space become a normal space? That is deliberate. Deleting it would glue "10 USD" into "10USD"; replacing it with an ordinary space keeps the words apart.

Does it change the page I am reading? No. It reads your selection and hands the cleaned text to the popup, so you decide where it goes. Nothing on the page is rewritten.

Does it send my text anywhere? No. See the privacy policy.
